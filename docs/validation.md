# Проверка 2026-09-14

Проверено на Godot 4.7.2 stable, macOS, Apple M4 Max. Рендер Forward+ / Metal.

- Импорт проекта и компиляция GDScript/шейдеров в целевой папке: без ошибок.
- `simulation_test.gd`: 259 проверок, 0 ошибок. Правила урона, способности, отмена готовности, JSON-снимки, помощь союзнику, щит, дебафф, 108 сочетаний волна/игроки/сложность, три босса, бонусы, победа/поражение, серии фиксированных симуляций.
- `input_test.gd`: клавиатурное подтверждение и отмена, переключение местного игрока, помощь и выход из помощи, выбор бонуса и переход к следующей волне — без ошибок.
- `npm test`: оба сценария сервера комнат проходят; распределение четырёх мест между ТВ и телефоном, запрет чужих фишек, вместимость, старт только ведущим, передача снимков только ведущим, разрыв соединения и уплотнение мест после ухода из лобби.
- `godot-integration.mjs`: два настоящих процесса Godot. Ведущий получает команду второго игрока; второй получает 15 снимков и наблюдает общий бросок. Оба завершаются успешно.
- Отдельная проверка браузерного контроллера через UI: вход в комнату настоящего headless Godot, место P2, выбор щита, готовность. Godot подтверждает получение обеих команд.
- Проверены живые кадры главного меню, арены, броска со следами/куполом, босса и карточек улучшений.
- Исправлено предупреждение о незавершённых AudioStreamPlayback при закрытии. После явной остановки голоса и завершения аудиокадра игра и тест управления закрываются без этого предупреждения.
- Проверены синтаксис JavaScript и shell-лаунчера, а также отсутствие ошибок whitespace в текстовых изменениях.

Не проверены: реальные физические геймпады, самостоятельные Windows/Linux/macOS-экспорты, слабые ПК, Smart TV, международная сеть. Публичный relay ещё не развёрнут. Баланс стартовый и требует живых партий. Автотесты не доказывают соответствие постановочному референсу.
